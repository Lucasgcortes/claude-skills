# launch-motion

A Claude skill that turns a product launch into an on-brand motion video, for any company.

It onboards your brand like an agency would (brand manual, channels, voice, colors, fonts, logo), then walks you from briefing to screenshots, script, frame approval and a finished MP4 cut to music, with sound effects. The video is built in code (HTML + GSAP), rendered frame by frame in Chromium and assembled with FFmpeg, so every frame follows your brand rules and the safe areas of each platform.

![catalog](examples/catalog-preview.gif)

## What it does
- **Agency-style brand onboarding → `brand.json`**: collects the brand manual, channels and voice first, asks only about gaps; colors mapped to roles, your licensed fonts or a close free Google font, headline style, accent usage, logo, voice. One file, reused for every video.
- **Guided flow**: brand → briefing → files → script → frames for approval → final video. You approve still frames before anything is rendered.
- **Motion library** (`scripts/motion.js`): word-by-word headlines, macOS-style window openings, impact words, rolling word lists, rebuilt charts and counters, rolling numbers, a product cut-out splitting into a fan of copies, a URL typed in an address bar with a cursor click, outro with logo.
- **Transitions with masks and overlays**: sweep, stack, expand-from-card, whip, shutter, blinds, through-the-word, blur, zoom in/out and camera punch-in, each with guidance on when to use it.
- **Music sync**: beat analysis and time-warping so scene changes land on the beat. No licensed track? It synthesizes a license-free one.
- **Sound effects**: synthesized whoosh, pop, tick, click, impact, notification, keyboard and swish, cued on every entrance, pop-up, exit, typing and click, mixed under the music.
- **Storytelling rules learned with real clients**: name the product in the first 3 seconds, pains as concrete scenes each answered by a solution scene, 2 s minimum reading time, no wiggling, the brand's own assets instead of redraws.
- **Layout rules**: safe areas for 9:16, 16:9, 1:1 and 4:5, grid, spacing scale, one focus per scene, automatic safe-area audit.

## Install
**Claude (claude.ai / desktop, Cowork):** download the latest `launch-motion.skill` from Releases (or zip this folder) and add it in *Settings → Customize → Skills*. Then just say "I have a launch to make a video for".

**Claude Code:** copy this folder to `~/.claude/skills/launch-motion` (or your project's `.claude/skills/`).

Requirements where the video is rendered: Node 18+, Python 3.10+, FFmpeg. `scripts/setup.sh` installs Playwright + Chromium, GSAP, librosa, scipy and Pillow inside the project folder.

## Quick start (manual)
```bash
bash scripts/setup.sh ~/videos/my-launch
cd ~/videos/my-launch
# edit brand.json, add your logo files next to it
python3 <skill>/scripts/brand.py brand.json kit --format 9x16
node <skill>/scripts/board.js video.html board "1 Open@2.6" "2 Impact@5"
python3 <skill>/scripts/music_gen.py music.wav --bpm 116 --dur 12
node <skill>/scripts/render.js video.html body.mp4 --w 1080 --h 1920
bash <skill>/scripts/finalize.sh body.mp4 music.wav final.mp4 0 body.sfx.json 0.6
```

## Structure
```
SKILL.md                 the flow Claude follows
references/              brand-intake, briefing, design (layout, transitions), music, technical
scripts/                 motion.js, brand.py, render.js, board.js, sheet.py, beats.py, finalize.sh,
                         layers.js (SingleFile pages), music_gen.py, sfx_gen.py, sfx_track.py, setup.sh, template.html
assets/sfx/              synthesized sound effects (CC0)
examples/                brand.example.json (fictional brand), catalog-9x16.html
```
