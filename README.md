# Claude Skills by Lucas Gama

Skills I build for [Claude](https://claude.ai) to automate creative and marketing work. Each one is a folder you can install in Claude (claude.ai, desktop app, Cowork) or Claude Code.

| Skill | What it does |
|---|---|
| [launch-motion](skills/launch-motion) | On-brand motion videos for product launches, for any company: brand onboarding, script, frame approval, animation synced to music, sound effects, MP4. |

More skills coming.

## Install a skill
**Claude (claude.ai / desktop):** download the `.skill` file from [Releases](../../releases) and add it in *Settings → Customize → Skills*.
**Claude Code:** copy the skill folder to `~/.claude/skills/<skill-name>`.
